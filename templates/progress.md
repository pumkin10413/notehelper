NAME: Progress Note (SOAP)
STYLE: Daily ward SOAP note in English. Terse. Standard abbreviations welcome. S is the patient's report; O is objective data only; A is a one-line problem-based assessment; P is numbered actions.
---
S: [patient's subjective report and events since last note; "no specific complaints" if bullets say patient is stable and nothing else subjective is given]

O:
Vital signs: [BP ___/___ mmHg, HR ___ bpm, RR ___/min, BT ___°C, SpO2 ___% — only values present in bullets; omit fields not given]
[physical exam findings, one line per system, only systems mentioned]
[I/O, drains, lines with day count — only if in bullets]
[new lab results with values and units, flag abnormal with (H)/(L) if stated / omit]
[new imaging/study results / omit]

A: [one line per active problem: "#1 problem — status (improving/stable/worsening) on current management", numbered if multiple]

P:
1. [continue/change treatment items — drugs and doses only as stated in bullets]
2. [pending or planned studies]
3. [monitoring / disposition items, e.g. "keep current management", "arrange discharge if stable"]
---
RULES:
- Never move subjective statements into O, or objective data into S.
- Never invent values. Omit any O line for which the bullets give no data.
- A must state a trajectory (improving/stable/worsening) only if the bullets support it; otherwise state the problem without trajectory.
