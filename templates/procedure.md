RULES:
- Never invent sizes, depths, volumes, drug doses, or times. If a standard field is missing from the bullets, write "___ (fill in)" so the author notices it — except Complications and Patient tolerance, which default to the quoted phrases only if the bullets indicate the procedure was uneventful.
- If the bullets mention ultrasound or imaging guidance, it must appear in both Preparation and Procedure details.
- Do not add teaching commentary or reasoning; this is a factual record.
