Gemini Nano not available? Enable it
  1. Use Chrome 138+ (check chrome://version). Regular Chrome, on this Mac.
  2. Enable flags, set each to Enabled, then relaunch:
    • chrome://flags/#prompt-api-for-gemini-nano
    • chrome://flags/#optimization-guide-on-device-model → Enabled BypassPerfRequirement
  3. Open chrome://on-device-internals (or chrome://components → “Optimization Guide On Device Model” → Check for update) and wait for the model to download (~2 GB, one time).
  4. Reload this page. First “Generate” may download the model — the status line shows progress.

Still nothing? This machine already has the higher-quality local pipeline: run python3 app/server.py and use http://127.0.0.1:8765 instead.
