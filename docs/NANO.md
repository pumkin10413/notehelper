# The page: `app/chart-nano.html` — bullets → Present Illness

A single self-contained HTML file that does **one job**: turn bullet points into a Present
Illness paragraph, following a template. No server, no network calls, no external scripts.
Generation runs on Chrome's built-in on-device Gemini Nano, so the bullets never leave the
machine.

`index.html` at the repo root is a **byte-identical copy** published via GitHub Pages at
https://pumkin10413.github.io/notehelper/ . **After editing `app/chart-nano.html` you must
re-copy it** or the hosted page goes stale:
```bash
cp app/chart-nano.html index.html
```
`.nojekyll` at the repo root is required — without it the Pages build runs Jekyll and has
silently failed before, freezing the site on an old commit for two days.

## What it does
- One textarea of bullets → one Present Illness paragraph → Copy.
- **Template** panel: the built-in wording rules, editable and saved in that browser
  (localStorage), with "Reset to built-in". Empty box = built-in template.
- **Model & setup check**: Prompt API flavour, availability, context window, echo-stub test.

## Two guards that must never be removed
1. **`detectStub()`** — some Chromium builds expose the Prompt API with no model and echo the
   prompt straight back. Without this the physician's own input would be shown as generated
   output and could reach a medical record. It raises and leaves the box empty.
2. **No speech input** — Chrome's `webkitSpeechRecognition` uploads audio to Google, a PHI
   breach. Voice belongs to the local whisper pipeline (`scripts/dictate.sh`).

## The template earns its length
Every rule in `BUILTIN_TEMPLATE` was added because a real model made that exact mistake in
testing: inventing an age or sex, inventing a disposition, computing "for 10 years" from
"since 2016", reading `r/o X` as "X was ruled out", inventing an (H) lab flag, and lumping
values behind "Laboratory results included:". Trim the prose if you must; keep the rules.

## If the page says the model is unavailable
Chrome blocks web pages from navigating to `chrome://` URLs, so these must be pasted into the
address bar. Do not hand anyone a `chrome://flags/#flag-name` deep link — it does nothing when
the flag was renamed or already ships on, which just looks like a broken link.

1. `chrome://version` — Chrome 138+, and real Chrome. Chromium usually has no model and echoes
   input back (which the stub guard catches).
2. `chrome://flags` → search `prompt api` → "Prompt API" = **Enabled** → **relaunch**. The flag
   does nothing until the relaunch happens.
3. `chrome://on-device-internals` — the authority on whether the model is present, and it names
   the failing requirement.
4. `chrome://policy` → search `GenAI` if you suspect IT blocked it.

## Maintaining it
Logic is exposed as `window.PI` so it can be exercised from the console without the UI:
```js
PI.detectStub(promptText, output)   // the echo-stub guard
PI.getAvailability()                // 'available' | 'downloadable' | 'unavailable' | 'no-api'
PI.BUILTIN_TEMPLATE                 // the wording rules
await PI.writePI(PI.BUILTIN_TEMPLATE, "65M, DM since 2016\nfever 3 days")
```
Behaviour lives in `BUILTIN_TEMPLATE` (what the paragraph should look like) and
`SYSTEM_PROMPT` (output-only, no preamble). Change the template first — it is the safer layer.
Remember `cp app/chart-nano.html index.html` afterwards.
